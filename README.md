# BPD Innovatech — React + Vite

Premium production-style website for BPD Innovatech.

## Stack
- React
- Vite
- Modern CSS
- No backend required

## Run locally
```bash
npm install
npm run dev
```

Then open the local URL printed by Vite (normally http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

The enquiry form opens WhatsApp with the submitted details. No form data is stored by the site.

## Deployment
The project can be deployed to Netlify, Vercel, Cloudflare Pages, or any static host. Build command: `npm run build`; publish directory: `dist`.
